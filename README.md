# Salman & Hani — Countdown

A single-page live countdown to the Nikah (Sunday, 11th October 2026,
12:30 PM IST) at **https://countdown.salmanwedshani.life**.

Pure HTML/CSS/JS — no build step, no dependencies:

- 3D flip clock (days / hours / minutes / seconds)
- Falling watercolor petals + rising gold fireflies on canvas
- Slow-turning golden light rays behind the clock
- Confetti burst every minute, bigger every hour, and a celebration
  loop once the moment arrives ("Alhamdulillah — married!")
- Seamless mirror-tiled floral valance shared with the invitation site
- Reduced-motion friendly; links to the main invitation

Deployed from this repo's `main` branch via GitHub Pages.
The wedding date lives in `<body data-target>` in `index.html`.
